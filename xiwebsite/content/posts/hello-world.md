想写博客这件事，断断续续想了很久。

真正开始动手，是因为发现：**写下来的东西，和想过的念头，完全是两回事。** 念头是散的，写下来就得成句、成段、有起承转合，于是被迫把含糊的地方想清楚。

## 这个模板是什么

这是一个**零依赖**的静态博客模板：

- 用 Markdown 写文章，放在 `content/posts/` 目录
- 运行 `node build.mjs`，生成纯静态 HTML 到 `dist/`
- 把 `dist/` 扔到任何静态托管上就能访问

不需要 `npm install`，不需要数据库，不需要 PHP 或者服务器运维。你需要的只有 Node.js。

## 三步开始

1. 改 `blog.config.mjs`：站点名、副标题、导航、友链
2. 改 `theme.config.mjs`：配色、字体、宽度、版式
3. 把 `content/posts/` 里自带的示例文章删掉，换成自己的

```bash
# 本地预览（改文件会自动重建）
node build.mjs --serve

# 正式构建
node build.mjs
```

模板只是壳。真正难的是持续写下去。
